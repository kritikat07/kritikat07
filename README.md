### 📌 Overview

**Stationery Nook** is a full-stack e-commerce platform designed for
college students to conveniently order **stationery products and
printing services online**.

browse products, manage their cart, place orders, and complete the
checkout process.

### ✨ Key Features

- 🛒 Add products to cart and manage cart items
- 💳 Checkout and payment functionality

- 🖨️ Stationery and printing service support

### 🎯 Problem Solved

Traditional stationery ordering can involve manual processes and
unnecessary delays.

**Stationery Nook** provides a centralized digital platform that
simplifies product discovery, ordering, checkout, and order management.

## 🚦 Crowd Flow Optimiser — Real-Time Crowd Management System

<p>
  <a href="https://github.com/kritikat07/crowd_detector">
    <img src="https://img.shields.io/badge/🔗%20View%20on%20GitHub-181717?style=for-the-badge&logo=github&logoColor=white"/>
  </a>
</p>

### 📌 Overview

**Crowd Flow Optimiser** is a full-stack crowd management and
simulation platform designed to **simulate crowd movement, detect
potential bottlenecks, and suggest alternative routes in real time**.

The system can be useful for large venues such as stadiums, railway
stations, airports, concerts, and large public gatherings.

### ✨ Key Features

- 🏟️ Venue layout builder
- 🚶 Crowd movement simulation
- 👥 Agent-based crowd simulation
- 📊 Crowd density monitoring
- 🚨 Automatic bottleneck detection
- 🔴 Live crowd-density heatmap
- 🔀 Real-time alternate route calculation
- 🧭 Dijkstra and A* pathfinding algorithms
- 📡 Real-time updates using WebSockets
- 📈 Live monitoring dashboard
- 📊 Simulation and historical reports
- 👨‍💼 Admin panel for venue and event management
- ⚡ Redis-based live crowd-state management

### 🧰 Tech Stack

**Frontend:** React, TypeScript, Tailwind CSS  
**Visualization:** Canvas API, D3.js, Recharts  
**Backend:** Java, Spring Boot  
**Communication:** REST API, WebSocket  
**Database:** MySQL  
**Caching:** Redis  
**Algorithms:** Dijkstra, A*  
**Simulation:** Agent-based / Queueing Crowd Simulation

### 🎯 Problem Solved

Large events can experience sudden crowd buildup around entrances,
exits, narrow pathways, and other high-traffic areas.

**Crowd Flow Optimiser** simulates crowd movement, detects areas where
crowd density becomes high, and calculates alternative routes to help
reduce congestion and improve crowd movement.

### 🌍 Potential Use Cases

- 🏟️ Stadiums
- 🚉 Railway Stations
- ✈️ Airports
- 🎤 Concert Venues
- 🎪 Large Events
- 🏏 Sports Events
- 🕉️ Large Public Gatherings
